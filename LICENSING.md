## No source code here, on purpose

That's deliberate. It isn't an oversight and it isn't a step toward publishing.

What's here: written documentation of what Conductor is, how it's structured, what modules it has,
how the runtime behaves, its security model, its testing record, and its measured results.

What isn't: source code, implementation detail, internal algorithms, interface definitions, config
formats, data structures, code samples, pseudocode that mirrors the implementation, internal file
paths, or anything private.

None of this is a partial release, a preview, or a redacted copy. It's documentation written for
evaluation. It covers *what* Conductor does and *why* it's built this way, never *how* any of it
works inside.

## For evaluation

This exists so Conductor can be assessed without handing over source first. It's aimed at:
