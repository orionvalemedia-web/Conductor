# Contributing

Code contributions aren't accepted.

This repo is documentation only. There's no source code here to contribute to. Pull requests
containing code will be closed without review.

Conductor itself is proprietary and developed privately. Its source isn't published here or
anywhere else, and it isn't open to outside contribution. See [LICENSING.md](LICENSING.md).

---

## Why

Conductor isn't an open-source project and isn't heading that way. Setting it up as if it were
open to contribution would misrepresent what it is, and taking outside code into a proprietary
codebase would create ownership questions in an asset whose clean provenance is one of the things
it gets judged on.

Saying so plainly costs nothing and saves anyone who was considering it the wasted effort.

## What is welcome

**Documentation corrections.** If something here is wrong, inconsistent, or contradicted by
another document in this repo, that's worth reporting. An issue describing the problem is enough,
no PR needed.

**Questions.** If something's unclear or under-explained, say so. Documentation that only makes
sense to whoever wrote it has failed.

**Pushback on the claims.** Everything here is written so it can be checked. If you think a claim
doesn't hold, or that a stated result doesn't support the conclusion drawn from it, that's a fair
thing to raise and it's welcome.

## What won't happen

- Pull requests containing code, in any language, for any reason
- Publishing the source, in whole or in part
- Relicensing Conductor as open source
- Feature requests. The roadmap isn't set through this repo.

## Security

Don't open a public issue for a suspected vulnerability. See [SECURITY.md](SECURITY.md).
