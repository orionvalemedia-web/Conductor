# Licensing, Partnership, and Strategic Discussions

Conductor is available for licensing, partnership, and strategic technology discussions.

---

## What's open to discussion

**Licensing.** Use of Conductor under a written agreement, scoped to what you actually need.

**Partnership.** Integration with an existing platform, or joint work where an agent-reliability
layer is one piece of something bigger.

**Strategic technology discussions.** Conversations about the technology itself: how it's built,
where it sits in an agent stack, and whether it fits a problem you're already working on. These
don't have to end in a transaction to be worth having.

Conductor is finished, tested, and independently verifiable. What shape an arrangement takes is a
conversation, not a fixed menu.

## What this documentation is for

So the technology can be assessed before anyone commits to anything.

The intent is that a technical evaluator can reach a real view, good or bad, from what's published
here. Claims are written to be checked, the conditions behind each result are stated, and the
known gaps sit next to the passes instead of waiting to be found later.

Start with [ARCHITECTURE.md](ARCHITECTURE.md) for the design and
[CERTIFICATION.md](CERTIFICATION.md) for what's been measured and what hasn't.

## Available beyond this repo

Under a signed agreement, and depending on where a conversation has got to:

- Source review
- The full internal audit, every finding at every severity
- The complete verification record and the conditions it was produced under
- A live demonstration, including the fail-closed and determinism demos in
  [TESTING.md](TESTING.md)
- Component-level architecture and interface documentation

## Status, up front

**In production use.** Conductor runs inside StudioOS, a Devadex Labs product, as the reliability
layer under that product's agent functionality. It's working software carrying real work.

**Unencumbered.** Conductor has never been sold, licensed, or distributed. No third party has ever
held a copy. Copyright sits with one identifiable author, with no third-party code and so no other
licence attaching to any part of it.

For a technology asset the second point is the structural one. There are no existing licensees
whose terms would survive a transfer, no copies out in the world, and no split in the rights,
which is what makes an exclusive arrangement possible at all.

Provenance and chain-of-title documentation are available under a signed agreement.
